# Polityka prywatności — CrossFit Personal Tracker

Statyczna strona z polityką prywatności aplikacji (PL/EN), publikowana przez
GitHub Pages: https://kciesielski-pl.github.io/crossfittrakcer_web/

- `index.html` — cała strona (bez zależności, style i skrypt w środku)
- `icon-512.png`, `apple-touch-icon.png`, `favicon.png`, `icon.svg` — ikona aplikacji
- `.nojekyll` — GitHub Pages serwuje pliki bez przetwarzania przez Jekyll

Adres tej strony wpisuje się w App Store Connect i Google Play Console jako
"Privacy Policy URL".
